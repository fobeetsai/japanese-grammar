## ✨ 核心特色功能

1. **全方位標籤即時篩選**
   - **JLPT 級數篩選**：N1（高級）、N2（中高級）、N3（中級）、N4~N5（初級）、口語・日常會話。
   - **五十音行順**：あ行～わ・ん行精準對應，無任何「其他」雜項。
   - **22 組專題系列**：如「〜わけ」、「〜こと」、「〜もの」、「〜ところ」、「〜ほど」等易混淆句型對比研讀。
   - **17 大語意功能分類**：如「原因・理由」、「逆接・讓步」、「條件・假定」、「時間前後」等。
   - **卡片徽章即時反查**：點擊卡片或表格上的任何級數、音行或系列徽章，自動過濾同類文法。

2. **頁內抽屜式詳解面板（In-Page Detail Drawer）**
   - 點選任何卡片直接在頁面右側滑出完整詳解，無白屏、無外部跳轉。
   - 完整展示：接續規則、中文深度精解、日文簡釋、日文例文、繁體中文翻譯、易混淆辨析。
   - 支援「上一條／下一條」快速翻頁、一鍵複製與加入收藏。

3. **貼心自學與課堂工具**
   - **振假名開關（<ruby> 切換）**：一鍵隱藏或顯示例句上方的漢字讀音，方便自我檢測漢字念法。
   - **隨機抽卡測驗（Flashcard Quiz）**：在目前篩選範圍內隨機抽考，支援翻牌顯示中文意思與例句。
   - **我的收藏筆記本**：點擊卡片右上星號加入收藏，並能一鍵匯出為 CSV（可匯入 Anki 或 Excel）、JSON 或文字檔。
   - **雙重視圖**：支援「卡片網格」與「資料表格」切換。
   - **深色模式**：支援夜間護眼深色主題。
   - **手機與平板自適應**：響應式設計，手機瀏覽器開啟順暢無礙。
